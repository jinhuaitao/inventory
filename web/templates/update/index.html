更新方式说明

  • 更新过程会校验安装包的 SHA-256（优先取发布中的 checksums.txt，缺失时回退到 GitHub 附件摘要），校验不通过会立即中止，不会替换任何文件。
  • 支持 tar.gz / zip 归档与裸可执行文件两种发布形态；裸二进制在落盘前会校验文件头是否匹配当前平台，避免误装其它系统的可执行文件。
  • 替换前会把当前可执行文件重命名为 <程序名>.old 作为备份，可用于手动回滚。
  • 替换成功后服务会自动重启，通常有几秒钟无法访问，刷新页面即可。
  • Windows 无法替换正在运行的程序，系统会把新版本下载为 <程序名>.new 并提示手动完成替换。
  • 数据库文件不受影响，更新不会改动任何业务数据。
